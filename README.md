## Why Zetacoin Wallet

Logos, marks and reference material are easy to find and easy to fake, which is why the official set lives on this account and nowhere else. If a download page uses a different mark, that is the first sign it is not the project.

None of it is required to use the wallet. The client installs, syncs, stakes and mines on its own, and the guides cover the parts that need a decision rather than a file.

- The desktop client holds ZET keys in a file you control and can back up yourself.
- Staking and mining both run from the same application, with no extra service.
- Addresses start with `9`; anything starting with `Z` belongs to the retired chain.
- Installers and their checksums sit on one release page, which is the only place to download from.

This repository is the asset shelf the project's pages draw from.
